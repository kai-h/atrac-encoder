## A.2 Scale factors

`SF[i] = 2^((i - 15) / 3)`, i = 0..63 (SF[0] = 1/32, SF[15] = 1, SF[63] = 65536). The binary stores these as IEEE single precision (table at 0x4BEBE8); values equal the formula rounded to float32.

## A.5 IMDCT window

For i = 0..255, with j = 255 - i:

```
wi = sin(((i + 0.5)/256 - 0.5)·π) + 1
wj = sin(((j + 0.5)/256 - 0.5)·π) + 1
w[i] = w[511 - i] = wi / (0.5·(wi² + wj²))
```

## A.7 Gain control

Level code L (4 bits) means gain `2^(4 - L)` (L = 4 is unity). Location code P (5 bits) means sample `8·P` within the 256-sample QMF-band block. Interpolation between levels uses the factor `2^(-1/8)` per step (table 0x48D770: `2^(-k/8)`, k = 0..7).

## A.8 Joint-stereo weights

Weight index W = (flag << 3) | level. `a = 2·level/7`, `b = 2·sqrt(2 - (level/7)²)`; flag 0 gives (w0, w1) = (a, b), flag 1 gives (b, a). Level 7 gives (2, 2) = no weighting.
